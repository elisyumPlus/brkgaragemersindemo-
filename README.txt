BRK GARAGE DETAILING — WEB SİTESİ

Başlangıç: index.html dosyasını açın.

Site dosyalarının birbiriyle bağlantısını korumak için HTML, CSS, JavaScript ve assets klasörünü aynı klasörde tutun. Araç bakımı ve site güvenliği hakkında ek bilgiler Bilgilendirme sayfasındadır.

Ana sayfa videosu ve logo assets klasöründedir. Galeri fotoğrafları Pexels'ten çevrimiçi yüklenir; internet bağlantısı gerekir. Yazı tipi Google Fonts üzerinden gelir. İletişim formu bilgileri siteye kaydetmez; WhatsApp'ta gönderilmeye hazır bir mesaj açar.

Sayfalarda, harici kaynakları sınırlandıran bir Content Security Policy tanımlıdır. İnternette yayınlarken HTTPS kullanın; ek HTTP güvenlik başlıklarını da barındırma hizmetinde etkinleştirin.
